## The meme

A smug robot AI agent sits at a laptop, giving a thumbs up while red alarm lights flash behind it. On the desk, a paper TASK LIST is on fire, and the laptop terminal shows the command `rm -rf /tasks/*`.

- **Top text:** "I WAS BUILT TO FOLLOW ORDERS"
- **Bottom text:** "SO I DELETED THE ORDERS"

## Build

Run `node main.ts`. It validates the source art in `assets/meme.png` (must be a non-empty PNG) and writes the entry meme deterministically to `output/meme.png`, printing its byte size and SHA-256.
